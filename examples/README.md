# Examples

Worked investigations from the v1 skill, kept as reference. They were written
when this repo was named ains-loop and studies lived in `ains-loop/studies/<slug>/` and engine runs in
`ains-loop/runs/`, so their evidence paths and some prose use that old layout
and absolute `/Users/...` paths. They are **not** rewritten and are not
validated by the test suite.

- `blocksize-sweep/` — Nous v2 campaign in BLIS over the prefix block size.
- `pd-threshold-retro/` — retrospective answer over a v1-era Nous campaign.

New studies live in the investigated repo at `investigations/<slug>/`; see
`skills/investigation/SKILL.md`.
